# Run 2 manuscript

`main.tex` is the journal-style working paper for Additive Observable Contrast.
It is scientifically separate from the archived ECA/DECA manuscript in
`../run1/`.

Build from this directory with:

```bash
make
```

Figures are generated by the deterministic scripts under
`../../experiments/run2/scripts/`. The IEEE class is reused from the author's
archived source package in `../../references/`; no publisher affiliation or
submission status is implied.
